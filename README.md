# Обёртка над Keitaro

Небольшой стол для двух операций из тестового:

1. Создать кампанию по названию, гео и ID оффера.
2. В существующей кампании добавить и удалить офферы и поправить доли.

Кампании, потоки и статистика живут в Keitaro. Локальная база (SQLAlchemy + Alembic) хранит ключ подключения и журнал созданий и отправок.

Открыть http://127.0.0.1:8000

## Как пользоваться

В шапке три раздела: «Новая кампания», «Кампании», «Подключение». Справа статус. «Боевой трекер» значит, что запросы идут в живой Keitaro. «Демо» значит, что ключ пустой и данные локальные.

### Подключение

1. В админке Keitaro открыть Профиль → API ключи и скопировать ключ.
2. На странице «Подключение» вписать адрес админки `https://tlgk.host/admin` и ключ, нажать «Сохранить».
3. «Проверить» должен ответить: API отвечает, домен `kylovoa.com`, группа `FORTESTS`, источник `FORTESTS`. Пустое поле ключа при сохранении оставляет уже записанный ключ.

Пока в этой строке есть «не найден», новую кампанию создать нельзя: нечего подставить в домен, группу или источник.

### Новая кампания

1. Название — как кампания будет называться в Keitaro.
2. Гео — коды стран из двух букв: `AU` или несколько через запятую, `MX, RO`. Эти страны уйдут на Google. Остальной трафик попадёт на оффер.
3. Оффер — начать вводить имя или ID и выбрать строку из списка. Под полем должно появиться имя выбранного оффера.
4. «Создать».

В трекере появится кампания с доменом `kylovoa.com`, группой `FORTESTS` и источником `FORTESTS`. В ней два потока:

- Flow 1 принимает указанные страны и ведёт на `https://google.com`.
- Flow 2 без фильтра, схема «лендинги и офферы», выбранный оффер на 100%.

Справа появятся ID, кликовая ссылка и ссылка в админку.

### Кампании

Список боевых кампаний. «Открыть» заходит в кампанию. Поиск фильтрует по имени или ID. Внизу журнал: когда кампания создана и когда доли отправлены в Keitaro.

### Кампания

Две ссылки сверху:

- Кликовая ссылка ведёт на `https://tlgk.host/{алиас}`. По ней трекер принимает клик и показывает лендинг. `https://kylovoa.com/...` сейчас не открывается: у домена нет DNS-записей, хотя в Keitaro он выбран доменом кампании.
- «Открыть в Keitaro» открывает карточку `https://tlgk.host/admin/#!/campaign/{id}/main`. Для этого нужно быть залогиненным в админку.

Дальше потоки. У оффера доля в процентах, статистика за сегодня и полоски кликов за 7 дней.

- «+» и «−» меняют долю на 1. Процент забирается у другого оффера или отдаётся ему, сумма остаётся прежней.
- «Удалить» снимает оффер: доля становится 0, кнопка меняется на «Вернуть». Оставшиеся активные офферы заново делятся на 100. Три оффера становятся 34 / 33 / 33, четыре — по 25.
- «Добавить оффер» внизу потока ищет оффер по имени или ID и тоже уравнивает активные доли на 100.
- Если сумма активных долей не 100, под списком есть «Уравнять».
- После любого изменения поток желтеет. В Keitaro ещё ничего не ушло. «Отправить в Keitaro» записывает доли. «Отмена» возвращает то, что было при загрузке. Снятые офферы в трекер не отправляются.
- «Обновить» заново читает кампанию из Keitaro и сбрасывает несохранённые правки.
- «Все офферы» открывает поиск и добавляет выбранный оффер в указанный поток.

## Что создаётся в трекере

- Домен `kylovoa.com`, группа `FORTESTS`, источник `FORTESTS`. Имена ищутся в Admin API, идентификаторы не зашиты.
- Ротация потоков по позиции, модель затрат CPC, стоимость 0, стоимость из параметра `cost`.
- Flow 1: фильтр «страны принимать» по указанным ISO-кодам, редирект на `https://google.com`.
- Flow 2: схема «лендинги и офферы», выбранный оффер со долей 100. Без фильтра, поэтому сюда попадает весь остальной трафик.

Несколько стран пишутся в один фильтр: `MX, AU, RO`.

## Доли в редакторе

На экране показывается поле `share` из Keitaro, как процент. После добавления, удаления и возврата активные доли заново делятся на 100. Остаток от деления достаётся последним активным офферам, затем строки сортируются по доле. Три оффера становятся 34 / 33 / 33, четыре — по 25. Кнопки `+` и `−` меняют одну долю на 1 и забирают или отдают этот процент другому офферу, сумма не прыгает. «Уравнять» нужно, если из трекера пришла сумма, отличная от 100. В Keitaro уходит только то, что на экране, без снятых офферов.

Колонка «Сегодня» — клики, уникальные, конверсии и доход за сегодня. Полоски — клики за 7 дней. Цифры берутся из `POST /report/build`.

## Запуск

Нужен Python 3.12.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
alembic upgrade head
uvicorn app.main:app --reload
```

Приложение само применяет миграции при старте. Команда `alembic` нужна, если хочется прогнать их отдельно. База — `data/app.db`.

Открыть http://127.0.0.1:8000

Ключ API: админка https://tlgk.host/admin/ → Профиль → API ключи. Его можно вписать в `.env` (`KEITARO_API_KEY`) или на странице «Подключение». Адрес админки в `.env` — `KEITARO_BASE_URL`. Пока ключа нет, интерфейс работает на демо-данных, чтобы кнопки можно было потрогать. Демо помечено в шапке и не пишет в боевой трекер.

Docker:

```bash
cp .env.example .env
docker compose up --build
```
